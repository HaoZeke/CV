* About :ignoreheading:ignore:noexport:
This is a two-phase exporter so ~tex~ can be handled in ~SRC~ blocks while still
being placed in a preamble.
* Preamble :ignoreheading:ignore:noexport:
To prevent issues with ~\es~ we need ~xspace~.
#+name: xspace
#+begin_src latex
\usepackage{xspace}
#+end_src
** Colors
I prefer [[https://macarthur.me/color/rgb(1,52,64)][this one]].
#+name: color
#+begin_src latex
\definecolor{cvhighlight}{RGB}{1, 52, 64}
#+end_src
** Tangle
Finally we tangle everything together and export once.
#+begin_src latex :results none :tangle preamble.tex :noweb yes
<<xspace>>
<<color>>
#+end_src
Which can be included once and for all.
#+LATEX_HEADER_EXTRA: \include{preamble.tex}
